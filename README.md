# Winners AI for HR

Interactive static website for **Winners Business Consultation & Training Services**.

## Live publishing with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main**, folder **/(root)**, then click **Save**.
4. After GitHub publishes the site, its address will be:
   **https://sahaarty0.github.io/winners-ai-for-hr/**

## Features

- AI Model Advisor (ChatGPT, Claude, Gemini, Copilot)
- Thinking Level Advisor
- Smart Prompt Builder
- 15 HR use cases
- AI output quality checklist

## Important

This is a browser-based **static prototype**. It does not call AI APIs or process model responses on a server. Don't embed API keys or sensitive employee data in public source files. The brand asset is embedded in `index.html` and the application is self-contained.
