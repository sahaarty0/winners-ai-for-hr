تهيئة SCA Gemini Backend

دي صفحة ملفات التثبيت فقط وليست Backend منشورًا. المفتاح بيتحط داخل Google Apps Script في حسابك، مش هنا.

1 — افتح Google Apps Script

إنشاء مشروع جديد

سمِّ المشروع Winners SCA Maturity Gemini Backend، واحذف الكود الافتراضي في Code.gs.

2 — انسخ محرك Code.gs

تنزيل الملف

3 — انسخ واجهة Index.html

داخل Apps Script اختر + → HTML وسمّ الملف Index، ثم الصق محتوى الملف التالي.

تنزيل الملف

4 — ضع المفتاح في المكان الآمن

Project Settings → Script Properties → Add script property

الاسم: GEMINI_API_KEY — القيمة: مفتاحك من Google AI Studio.

يمكن إضافة GEMINI_MODEL بعد اختبار النماذج المتاحة. لا تكتب المفتاح داخل الكود أو في صفحة عامة.

5 — انشر بأمان واختبر

Deploy → New deployment → Web app

Execute as: Me — Who has access: Only myself. افتح رابط /exec الناتج واختبر اتصال Gemini.

مهم: لا تختار Anyone أو Anyone anonymous؛ وإلا قد تعرض مفتاحك لاستهلاك غير مصرح به.

الملفات الأصلية محفوظة في مستودع Winners GitHub. لا يوجد API Key مخزن هنا.
